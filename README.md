# MyStillio MVP 0.1

Перший локальний прототип цифрової винокурні. Інтерфейс українською, адаптований до телефона.

## Реалізовано
- Склад сировини з залишками та списанням у брагу.
- Браги з частковим використанням на перегонки.
- Перегонки з фракціями, які стають партіями рідин.
- Напої/рідини з об'ємом, міцністю та місцем зберігання.
- Бочки з контролем місткості, заливкою та відбором.
- Історія подій, IndexedDB, експорт/імпорт JSON.
- Маніфест PWA та офлайн-кешування після першого відвідування через HTTP(S).

## Як запустити
Варіант 1: розмістити весь вміст папки на HTTPS-хостингу (наприклад, статичний хостинг). Відкрити адресу в Safari/Chrome. Для встановлення на iPhone: Safari → Поділитися → На початковий екран.

Варіант 2: на комп'ютері з установленим Python у папці проєкту виконати `python3 -m http.server 8080`, тоді відкрити `http://localhost:8080`.

Не запускайте `index.html` через `file://`: IndexedDB та service worker можуть працювати непередбачувано.

## Обмеження
Це MVP, не production. Дані тільки на одному пристрої. Немає сервера, авторизації, синхронізації, QR, фото, детальних замірів, купажування, температурних поправок, багатокористувацького доступу. Необхідні тести на реальних пристроях та аудит операцій обліку перед комерційним запуском. Імпорт JSON довіряйте лише власним файлам. Заливки різних партій у ту саму бочку заблоковані до реалізації коректного купажування.
